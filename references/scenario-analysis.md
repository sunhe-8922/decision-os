# Decision OS — 情景推演与二阶效应

## 三情景框架

每个重大决策必须构建三个情景。禁止只看单一结果路径。

```markdown
## 乐观情景（Bull）
概率：___%（三概率之和 = 100%）
核心假设：___
关键指标变化：___
预期结果：___
触发信号：___

## 中性情景（Base）
概率：___%
核心假设：___
关键指标变化：___
预期结果：___
触发信号：___

## 悲观情景（Bear）
概率：___%
核心假设：___
关键指标变化：___
预期结果：___
触发信号：___
```

## 情景校准规则

1. **概率锚定**：先定 Base（40-60%），再分配 Bull 和 Bear
2. **禁止极端**：单一情景概率 10-70%
3. **对称性检验**：Bull + Bear < 30% → Base 定义太宽

## 期望值计算

```
期望收益 = Bull概率 × Bull收益 + Base概率 × Base收益 + Bear概率 × Bear收益
```

期望收益 < 0 → 该选项直接淘汰。

## 二阶效应分析

在每个情景内部分析连锁反应：一级（直接结果）→ 二级（连锁反应）→ 三级（系统性影响）

### 示例1：创业决策

| 效应层级 | Bull | Bear |
|---------|------|------|
| 一级 | 产品成功上线 | 产品延期 |
| 二级 | 用户增长→融资→扩张 | 现金流断裂→裁员 |
| 三级 | 行业地位→并购机会 | 个人信用受损→职业倒退 |

### 示例2：资产配置决策（买房vs基金）

| 效应层级 | Bull（房价涨+基金涨） | Bear（房价跌+基金跌） |
|---------|----------------------|---------------------|
| 一级 | 资产增值20%+ | 资产缩水30%+ |
| 二级 | 可加杠杆扩大收益 | 流动性枯竭→被迫割肉 |
| 三级 | 财务自由加速→投资能力升级 | 负债率攀升→影响生活质量/职业选择 |

### 示例3：跳槽决策

| 效应层级 | Bull（新公司上市） | Bear（新公司裁员） |
|---------|-------------------|-------------------|
| 一级 | 薪资涨40%+期权 | 试用期被裁 |
| 二级 | 行业地位提升→更多机会 | 收入中断→房贷压力 |
| 三级 | 职业跃迁→5年3x | 被迫降薪就业→职业倒退2年 |

## 操作规则

1. 每个情景至少分析到二级效应
2. Type 1 决策必须分析到三级效应
3. 二级效应出现不可逆伤害 → 该情景概率上调
4. **组合型决策**：对组合中的每个子项单独分析一二级效应，再分析组合整体的三级效应
